# 导入样例

仅含虚构数据，依赖 `tools/seed_demo.py` 的演示专业、班级、教师和课程。

| 文件 | 上传业务类型 | 注意 |
| --- | --- | --- |
| students.csv | 学生名单 | 新增 DEMO0002，不创建账号 |
| courses.csv | 课程表 | 新增 DEMO002，不自动开课 |
| offerings.csv | 开课表 | 为 DEMO 课程新增第二学期开课 |
| grades.csv | 成绩表 | 填目标开课编号，演示学生必须已选课 |
| rewards.csv | 奖惩记录 | 新增虚构奖项 |

成绩体验：用 `demo_student` 登录，在选课页面选择演示数据库课程，再用管理员上传成绩表并填实际开课编号。没有选课时提示错误是预期行为。

上传不等于入库。展开各行核对、修正或排除，更新已有记录需勾选允许更新，再确认导入。重复奖惩或相似开课会被拦截。

CSV 使用 UTF-8。Excel 学号优先使用文本格式；明确的纯零补位格式（如 0000）会保留，已经丢失的前导零无法恢复。

# community-agent 当前实现状态核查

核查日期：2026-10-10。依据当前源代码、阶段交付文档及本轮隔离测试，不以历史计划中的“完成”字样单独判断。

结论：项目已具备本地证据问答和贴吧在线采集闭环。P0–P4 的基础工程已落地；P5 的自动规划、语义候选检索和有界探索部分落地，尚未达到完整语义质量验收标准。P6 为按需扩展设计。

## 3. P5 已落地部分

1. **单一对话入口和内部自动规划**：默认进入助手；后台选择本地、在线、资料充分性判断或澄清。支持查找、口碑、原因、比较、热门等内部分析策略，保留高级手动采集入口。当前代码还包含“金球奖”领域歧义澄清和同会话领域继承保护，这只是特定表达的补充规则。
2. **统一有界预算**：默认最多 3 个查询、全轮 20 次帖子额度；符合用户扩量原话时上限 40。补读原帖也占额度；评论通常最多补 3 帖、每帖 20 条一级评论；默认总时限 180 秒。明确只看本地或不采评论有额外校验。
3. **真实本地向量检索**：可用远程兼容接口或 FastEmbed；当前本机选用 `BAAI/bge-small-zh-v1.5`。以快照片段缓存向量，并与字面候选合并、去重；普通本地加载使用 `local_files_only=True`。每次候选切片和新嵌入量有上限，返回部分覆盖，不能当全库精确命中数。
4. **逐批独立核验和工作记忆**：采集每批导入后逐帖判断相关/无关/待核实，核验引文来自当前候选；笔记按快照持久化，同快照免重复、新版本重验。默认最多 8 次核验、扩量 12 次，累计核验时间 40 秒。工具记录保存参数和引用，工作上下文主动重建，需要原文时回到可撤销快照读取。
5. **结果资格与证据用途分离**：已核验相关的引用进入正式卡片，无关依据留在筛选详情，未审阅/待核实或混合依据进入待核实区。数量按实际卡片统计，评论不能继承父帖相关性。旧回答没有核验笔记时保持兼容展示，并非所有历史结果都经过三态审核。
6. **少量评论核验与用户更正**：当前每轮最多独立核验 2 条评论，并受总核验预算约束；支持用户逐条修改既有有效审核记录、保存更正前后值并重算卡片，标记原回答需要复核。
7. **候选关系和一次有界试探**：保存别名/相关主题候选及原文依据。两个不同帖子支持同一别名且引文有效，初始查询不足 3 项时，可用预留最多 3 帖额度追加一次称呼搜索；目标保持不变。记录分支新增/重复快照、初筛相关项、未核实项、耗时与配额。
8. **评测入口**：`evaluation.py` 和 `tools/evaluate_p5.py` 可对独立标注集合比较明确名称、固定扩展、有界探索的已知样例覆盖、已判断项精度、漂移、重复和成本；当前没有真实人工金标质量成绩。

## 4. 尚未实现或尚未验收

- 用户更正后的自动重新回答：当前只更新审核记录、卡片和提示，原回答文本保留。
- 完整别名确认机制及已核实别名的跨任务自动复用；候选关系不等于已确认别名知识库。
- 通用探索控制：当前有一次受证据约束的别名试探，尚无普遍根据边际收益动态改写、增减或停止查询的策略。
- 全面评论审核、片段不足时自动补读全文，以及完整结果资格设计；当前是有预算限制的片段核验。
- 独立人工标注集、同预算对照实验、真实误排/漏检/漂移测量、代表性口碑采样。测试通过不能证明模型判断准确或语义召回提高。
- P6 的更多平台研究集成、更多导入格式、增量采集与变化分析、按规模建设调度队列或专门向量数据库。底层已有快照版本和文件队列，不等于这些完整产品能力已实现。

# 单轮采集共用浏览器

2026-09-22：助手的一次在线采集共用一个爬虫子进程、Playwright上下文及页面。每个查询和补采评论仍有独立任务ID、输出目录和来源记录。

`CollectionAdapter`请求持久会话。管理器首次启动进程，后续通过本地原子文件队列发送分支；贴吧爬虫只在进入会话时启动浏览器、检查登录，之后顺序执行搜索和详情采集。每次分支重置查询词、来源关键词、采集类型、配额及保存目录。语义筛选期间保持会话，整轮结束关闭。

分支完成由独立结果文件通知管理器，不通过网页内容或日志判断成功。关闭优先通知子进程取消并退出，5秒内未结束则使用原有进程树终止流程；已完成分支不被改写为“已停止”。父服务退出或会话空闲超过330秒时工作循环退出。登录阶段尚未进入工作循环，取消由管理器的进程树终止兜底。浏览器异常退出后，本轮不自动重启另一个浏览器；手动爬虫仍走原有单次模式。

验证：

- 159项研究助手自动测试通过。
- 真实本地Chromium、实际子进程，模拟3次搜索和2次详情采集：只启动1次浏览器，共用同一页面/上下文，5个独立输出目录。
- 采集中取消、等待登录时取消、进程崩溃：子进程和浏览器驱动均已退出；崩溃后禁止静默重新启动。
- 原有8项爬虫配额/查询/登录边界检查通过。
- 测试页面仅about:blank，未调用外部模型，也未进行真实贴吧采集。报告见[browser-session-validation.json](browser-session-validation.json)。

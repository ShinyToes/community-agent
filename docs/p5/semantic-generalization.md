# 有界语义泛化与候选核验

2026-09-21 更新。目标是理解需求后适度扩展，不为动漫、某个角色或某个标题句式写特殊规则。

## 流程

1. 内部规划增加 `semantic_scope`：对象范围、内容意图、纳入/排除标准、各查询的探索方向。最多三个互补查询，可涵盖核心概念、合理子类或实例、社区表达；不要求每条都包含原始上位词。具体实例是探索入口，不是已验证别名。
2. 新任务在已采集来源内枚举最多40个独立帖子，不再先要求匹配原始关键词。支持新语义范围的计划增加一次最多20秒的模型初筛，逐条记录 relevant / irrelevant / uncertain、理由与逐字原文引用。检查ID、数量、重复、标签及引用是否确实来自片段。
3. 补采评论只选初筛为相关的候选，仍遵守原来的总配额。审阅失败不退回随意补采。旧版无semantic_scope的计划保留兼容路径。
4. 回答环节直接获得本轮候选清单，仍须调用read_evidence核验引用。待核实项可继续读；初筛标签不是事实证据，不能替代完整正文。候选数、核验数、展示数与相关总数须区分。
5. 默认仍最多3查询、20次帖子采集配额；明确扩量最多40，既有总时限不变。候选枚举计入回答工具次数；审阅计入规划调用次数及总时限。界面没有新增配置表或确认步骤。
